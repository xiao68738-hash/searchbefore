# 網站／原生備份欄位相容修正

## 範圍

承接已合併的 PR #147。只更新網站 JSON 備份白名單及離線快取版本，不發布 Android，不變更 Firebase 規則，不操作雲端或手機既有紀錄。

保留原生紀錄的 `waterRecorded`、`actualAmount`、`actualAmountUnit`、`notes`、`registrationId`、`harvestForm`。用量、單位、字數、布林型別及安全編號皆驗證；不開放任意欄位，也不把匯入資料視為可用藥或檢驗合格的依據。

## 驗證

- 新增合成資料的匯入／匯出往返測試，含小數用量、中文備註、登記編號、收穫型態，以及錯誤型別、非法單位、負數、超限、路徑型編號拒絕測試。
- 本機匯出實際 Play v5 的備份副本：2 田區、1 用藥、4 農務、0 配方。網站讀取→匯出→讀取一致，來源紀錄欄位遺失數 0；未覆寫手機資料。
- 完整 Node 回歸與網站建置通過。新工作目錄首次測試缺少 npm 相依套件，安裝 lockfile 指定套件後重跑全套通過；沒有降低搜尋測試斷言。
- 私人備份只存在專案外的本機 private 目錄，不納入 Git、發布檔或測試 fixture。

這是格式相容驗證，不等於真實雲端新建紀錄、另一裝置下載及完整 UI 操作都已驗收。
