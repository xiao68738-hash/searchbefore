# 清爽藥劑卡（使用者選定第一版）

## 變更範圍

- 作物 → 病蟲害 → 登記藥劑：名稱、濃度／劑型、商品與作用機制分區。
- 倍數與安全採收期並排；特大字或窄卡片改直排，不裁字。
- 來源 dose 欄位為「每公頃使用用藥量」。普通稀釋用法且值為純質量／體積時標明「每公頃每次用量」；種子處理等特殊用途或其他格式保留原單位及附註。
- 採收期缺值顯示「請查產品標示」；種子處理缺值顯示「不適用」。保留明確零值、區間及備註延長天數。
- 配藥計算為主要按鈕，紀錄用藥／存入配方為次要按鈕。原用法索引與動作未更換。
- 保留 MRL 提醒、特殊用途分組、完整附註及回報功能。
- 作物／病蟲害列隨頁首高度定位；同步更新 SW 快取版本以觸發新版提示。

## 驗證

- 新增單元測試：用量單位、特殊用途、未知／零／區間採收期、輸出跳脫及動作索引。
- 原型工作樹曾跑過 44 個測試檔及 12 項獨立 Chrome 檢查；其中兩個測試檔屬尚未發送的自動驗收工具，另一個屬 PR #145，並非本 PR 內容。本 PR 分支共有 41 個測試檔。
- Chrome 檢查含 320/390/720px、深色及特大字、配方／紀錄／計算動作、脫克松 × 豌豆種子處理。
- 最終 PR 分支另跑其完整測試、建置及成品檢查。瀏覽器驗收工具及截圖保留本機，不因本 PR 上傳。
- 嵌入 DATA 不變。沒有修改倍數、採收計算、殘留清單或任何登記資料。
- 動態文字以 esc() 或 textContent 輸出；沒有新增權限、外部服務或資料上傳。

## 界線

本次是瀏覽器與本機程式驗證，不等於 Android 實機或正式 Firebase 權限驗收。沒有變更 AAB、versionCode 或 Play Console 送審狀態。合併及部署是後續獨立動作。
