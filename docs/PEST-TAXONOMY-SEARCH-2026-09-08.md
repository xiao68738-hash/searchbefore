# 夜蛾相關條目／鱗翅目搜尋歸納修正

查核日期：2026-09-08。基準：main `676d285`（PR #137），內嵌登記資料版本 2026-07-21。

## 原因

不是原始夜蛾用藥被刪除，而是搜尋沒有分類關係：

- `isParentOf()` 原先只辨認以「類」結尾的群組，並比對共同字根；「鱗翅目害蟲」不符合，不能連到「夜蛾類」。
- 病蟲害篩選及作物用藥總覽都用 `includes()`，搜尋鱗翅目只命中原名含鱗翅目的登記。
- `夜蛾科` 和資料內的 `夜蛾類` 沒有搜尋對照。
- 病蟲害不超過 12 項的作物原先不顯示篩選欄。
- 原相關分類僅提供切換提示，不能就地展開藥名。

## 這次範圍及依據

所有對照只用於搜尋／可發現性，**不是登記適用範圍的法律認定**。歷史文獻只支持分類，不用來替換現行藥劑用法。

| 搜尋對照 | 一手依據與用途 |
|---|---|
| 鱗翅目 → 夜蛾科／夜蛾類 | 農業部[斜紋夜盜蛾圖鑑](https://kmweb.moa.gov.tw/theme_data.php?id=292&theme=pest_map)列出鱗翅目、夜蛾科；將夜蛾科作為現有「夜蛾類」的搜尋入口，不改原登記名稱。 |
| 斜紋夜盜蛾 → 斜紋夜蛾 → 夜蛾類 | 同一圖鑑及[甘藍主題館斜紋夜蛾](https://kmweb.moa.gov.tw/subject/subject.php?id=13449)，按同種名稱建立搜尋對照。 |
| 甜菜夜蛾 → 夜蛾類 | 花蓮區農業改良場[青蔥綜合防治甜菜夜蛾](https://kmweb.moa.gov.tw/knowledgebase.php?func=1&id=416365&keyword=&type=13151)，2022-06-20，明列鱗翅目、夜蛾科。 |
| 秋行軍蟲 → 夜蛾類 | 防檢署[秋行軍蟲監測公告](https://www.aphia.gov.tw/theme_data.php?id=17124&theme=NewInfoListWS)，2020-03-04，明確稱為夜蛾類害蟲。僅取分類，不採用舊防治階段／用法。 |
| 切根蟲／切根蟲類 → 夜蛾類 | 臺南區農業改良場[觀葉植物害蟲之生態與防治](https://book.tndais.gov.tw/Brochure/tech99.htm)「切根蟲」列為鱗翅目、夜蛾科；另有[農技報導 87 號](https://book.tndais.gov.tw/Brochure/tech87.pdf)說明為夜蛾類幼蟲。前者本輪搜尋索引可取得分類段落，直接開頁逾時；並以後者索引段落交叉核對，未據此認定新的施藥用途。 |

本次明確上位對照涵蓋現有資料中的夜蛾類、斜紋夜蛾、甜菜夜蛾、秋行軍蟲、切根蟲。**不是完整鱗翅目分類表**：不因字尾有「蛾」就自動新增小菜蛾、毒蛾或螟蛾等科的上位對照；畫面明示分類表尚不完整。原有其他群組的完整字根提示維持，新增分類必須再附依據與正／負例測試。

## 顯示行為與安全界線

1. 作物仍只從該作物原有直接登記取候選，不借用別的作物或上位作物群組。
2. 搜尋「鱗翅目害蟲／鱗翅目／鱗翅」及「夜蛾科／夜蛾類／夜蛾」可找到對照中的原條目。即使該作物沒有上位登記，仍可找到它已有的子項，但不新增不存在的上位登記頁。
3. 子物種查詢不將兄弟物種或上位登記混成直接命中；另在原登記頁提示相關上位，供自行核對。
4. 同作物相關分類用藥總覽依原防治對象分組，可展開藥名，再進入原登記頁查看用法。筆數與去重藥名數分開標示。
5. 主清單、計算、紀錄用藥、配方索引仍只取所選的原登記條目。倍數、備註、採收期、用藥登記資料皆未修改。
6. 分組預覽不套用主清單採收期篩選，畫面明示此限制；切換原登記頁時依原流程重設篩選。
7. 藥名、對象、分類標籤以 HTML 逸出輸出；本次改動的點擊參數以 JSON 字串再做 HTML 逸出，避免引號破壞事件處理式。
8. 新 HTML 搭舊 `query-aids.js` 時退回名稱搜尋／舊相關提示，不拋錯，不猜測分類。Service Worker 更新版本以取得新檔案。
9. 沒有新增網路 API、登入權限、遙測、雲端寫入或套件依賴；這不是整站零風險保證。

## 全庫查核結果

以本次明確對照、同作物原始列統計：

- 178 個作物的 2,229 筆夜蛾相關原登記用法，可由鱗翅目搜尋找到；不是新增 2,229 種藥劑。
- 91 個作物同時有鱗翅目與夜蛾相關登記，可提供上下位分組。
- 「蔥」：原鱗翅目 3 筆／1 種普通名稱；夜蛾類 20 筆／11 種；甜菜夜蛾 1 筆／1 種。總覽搜尋鱗翅目後去重為 12 種普通名稱。
- 查詢前後 DATA 序列化完全相同；所有總覽列保留原登記物件參照。編輯時內嵌 DATA 原文保持不變。
