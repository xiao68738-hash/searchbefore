# 全庫搜尋群組與別名修正

日期：2026-09-09。基準：main d0a184e（PR #138 已合併）；登記 DATA 仍為 2026-07-21 版。

## 問題與修正

原程式依「類」字尾截出字根，再用 includes 判斷從屬；名稱相似可能被錯認為上下位，也漏掉沒有共同字根的成員。改為明列來源核對過的對照，未知名稱不推斷從屬。

- 補齊前次全量檢核的 16 個具體群組、91 組漏接關係。
- 本機既有名稱間共有 149 組官方明確上下位關係，另保留秋行軍蟲的 2 組獨立科別證據。
- 增加水螟類、草螟蛾類、松葉蜂科這 3 個有來源的查詢入口，即使本機沒有同名上位登記，也能搜尋同作物既有子項。
- 補 24 個缺漏別名，加上原本已能字面命中的 2 個，共 26 個官方單一對應別名。
- 完整群組名不再作為其他群組名的片段：「螟蛾類」不能因「草螟蛾類」含有該字串而擴大。
- 部分分類名稱仍可搜尋；完整物種別名才做對照，不把「紫」直接推成大螟。

| 對象 | 修正後 |
| --- | --- |
| 大螟／紫螟、稻螟蛉 | 夜蛾類；不是螟蛾類 |
| 一點螟蟲、二化螟蟲、大菜螟、玉米螟、瘤野螟、菜心螟 | 官方螟蛾類查詢群組；不據此宣稱現行科別都相同 |
| 甜菜白帶野螟蛾 | 草螟蛾類，不再用字根建立螟蛾類從屬 |
| 褐帶紋水螟蛾 | 水螟類，不再用字根建立螟蛾類從屬 |
| 松綠葉蜂 | 松葉蜂科；不直接放入官方葉蜂類 |
| 番茄斑潛蠅 | 潛蠅類；不宣稱官方斑潛蠅類的子項 |
| 地下部線蟲類／根瘤線蟲／穿孔線蟲 | 不將官方平行項目互推為上下位 |

## 來源與資料欄位界線

官方查詢群組不是完整生物分類，更不是登記用途互用的法律結論。

1. 官方案例來源：[農藥資訊服務網病蟲分類樹](https://pesticide.aphia.gov.tw/information/Query/Bug/?bug=B38&farm=C0507&userange=1)。2026-09-08 從瀏覽器 DOM 讀取 1,414 個節點，保留全部本機 289 名稱相關的 336 個節點及祖先。快照為 tests/fixtures/pest-official-tree-2026-09-08.txt，FNV-1a32 f4384f4f。
2. 26 個單一對應別名按完整 1,414 節點查重。別名查重快照為 tests/fixtures/pest-alias-uniqueness-2026-09-08.txt，FNV-1a32 1dd71ad。「蚜蟲」對應 27 個節點，不可自動指定物種；保留泛稱搜尋候選。
3. 秋行軍蟲及原夜蛾科對照沿用 [前次證據清冊](PEST-TAXONOMY-SEARCH-2026-09-08.md)。官方 UI 的「其他」不應撤銷已有生物分類證據。
4. 大螟科別依[農試所名錄](https://www.tari.gov.tw/sub/table/index.asp?Parser=5%2C29%2C371%2C350%2C%2C%2C%2C%2C%2C%2C2)與[臺中場二化螟與大螟研究](https://kmweb.moa.gov.tw/knowledgebase.php?func=1&id=296126&keyword=&type=13178)；稻螟蛉依[防檢署植物保護圖鑑](https://www.aphia.gov.tw/Publish/plant_protect_pic_8/ricePDF/03-21.pdf)。僅用分類證據，不採用歷史用藥建議。
5. 夜蛾科不再正規化成夜蛾類；前者只對照已核實的六個名稱，後者依官方查詢樹。搜尋夜蛾科仍可看到官方夜蛾類入口，但不因該入口推論全部成員現行科別，例如小造橋蟲暫不列為已核實夜蛾科。
6. pestRelation 回傳 official-group 或 scientific，查詢入口另標記 group-query；來源類型在程式中分開，未新增使用者需操作的選项。

## 明確保留的未完成項目

- 扁蝸牛、炭疽病、立枯病、黃葉病同名多碼：只保留原名查詢，不自動建立從屬或重寫原登記，需再查回逐列官方代碼。
- 害蟲、真菌及類真菌病害、寄生性線蟲類等廣泛根節點的 229 組缺口未自動開放。這次不把全部藥劑拉入極廣泛入口。
- 未宣稱全部物種的現行分類學、所有可能別名或每筆登記原始 ID 均完成文獻覆核。
- 本次不處理 OCR、Android v3 ANR、Google Play AAB 或真實帳號雲端還原。

## 驗證與資安

- 新增全量測試，獨立從官方快照推導本機名稱關係，核對 289 名稱、83,232 組有向配對，不能只用產品對照表自己驗證自己。
- 149 組官方關係與 2 組秋行軍蟲關係全部可搜尋；26 個別名全部命中，4 組舊字根誤納不成立。額外 3 個入口另以官方節點路徑驗證。
- 同名多碼、泛稱、部分字串、上下位方向、跨作物隔離、原始資料不變均有回歸測試。
- 原畫面函式測試保留 HTML／事件參數逸出、原登記點擊目的地、舊快取相容性；未知惡意字串現在不會被錯認成群組成員。
- 沒有新增套件、網路端點、權限、遙測、登入／同步寫入；來源快照只含官方公開分類文字與代碼。
- 更新 Service Worker 快取版本；測試來源與說明文件不進發布成品。壓縮成品另跑搜尋正例／負例。
- 原 DATA、倍數、用量、備註、採收期完全未修改。分類搜尋仍由同作物既有條目提供，不能擴大用藥登記適用範圍。

測試通過不等於全站資安零風險或 Android 實機驗證完成。
