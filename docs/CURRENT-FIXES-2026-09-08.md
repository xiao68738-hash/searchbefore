# 田區歸屬與農務同步修正（2026-09-08）

工作分支：`agent/android-release-3`。本輪修正仍在本機，沒有部署網站、發布 Firestore 規則、上傳 AAB 或推送 PR；先前既有變更均保留。

## 已修正

### 田區計數、明細及匯出不一致

先以回歸測試重現：新田區在沒有指定田區用藥的情況下，被計為 1 筆用藥。

`index.html` 的 `recordMatchesPlot` 現在必須同時符合明確田區 ID 和作物相容性。清單、輪用摘要及田區篩選匯出不再把同作物未指定田區的紀錄當成該田區實際紀錄，與既有作業時間軸一致。

另加「同作物用藥尚未指定田區」提示，清楚說明不列入本田區統計，也不表示已確認可採收。所有舊資料仍留在完整用藥歷史及完整備份，不會刪除、指派或搬移。安全採收引擎及傳入的完整紀錄沒有變更。

### 農務內層欄位變更漏傳

先重現 `sameContent` 把 `details.quantity` 的 1→2 誤認成內容相同。原因是 `JSON.stringify` 的 replacer 鍵名陣列會在每一層過濾欄位，捨去農務內層內容。

`cloud-sync.js` 改成逐層排序物件鍵、保留陣列順序，僅排除最外層同步時戳。內層修改現在會產生新時戳並列入上傳清單，不會改動傳入原始物件。這項修正不等於解決跨裝置同時編輯與時鐘偏差。

快取更新為 `v0.3.9.9-sync-session-guard-plot-scope-2026-09-08`，部署後才會通知使用者更新。
