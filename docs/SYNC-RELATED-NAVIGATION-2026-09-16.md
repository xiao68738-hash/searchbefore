# Web 同步與相關防治對象導引修復

2026-09-16，Web 候選 v0.3.10.0。本 PR 不更換 Android TWA，不修改 Firebase Rules，不操作使用者雲端資料。

## 修正

- 移除用戶端 `updatedAt > syncLastAt` 的讀寫篩選，避免離線舊編輯延遲上傳後永遠被漏讀。
- 每輪完整核對三個既有集合，要求 `getDocsFromServer`，不把離線快取當作雲端備份成功。
- 每筆待上傳資料透過 Firestore transaction 重讀最新版再比對；交易後保留等待期間新增的本機編輯與刪除。
- 編輯時間戳大於已知舊紀錄；保留帳號隔離、主動同步同意、取消與重試。
- 移除清單頂部的相關分類展開總覽；改成清單底部「也要看看蔥 × 夜蛾類用藥嗎？」連結。
- 原登記分開呈現，不把夜蛾類、甜菜夜蛾或鱗翅目害蟲的藥劑混成同一清單。

## 驗證與限制

- 回歸涵蓋三集合延遲上傳、延遲刪除、偏斜 checkpoint、交易中遠端更新、伺服器失敗、重複同步不重寫與帳號取消。
- 本機瀏覽器確認蔥 × 甜菜夜蛾只有 1 筆；點底部夜蛾類連結為 20 筆，不混入甜菜夜蛾藥劑。
- 導引是清單最後的普通排版元素；已驗證從舊快取更新，不清除資料。
- 原始 DATA SHA-256 保持 `b986f7b0c0dce60738a6850601cee670104a6dd7264b605ef4d59fbe3196950e`。
- 同步測試使用 Fake Firebase SDK。真實兩裝置登入、上傳、還原仍待驗收，不宣稱已完成。
- 完整伺服器讀取會增加用量；未變資料不重写，既有 debounce 保留。後續須觀察配額，不能退回會漏讀的時間篩選。
- 同時編輯仍採既有 updatedAt 衝突規則，不宣稱解決不同裝置所有時鐘偏差。

執行 `node tests/run-all.js`、`node scripts/build-release.mjs`、`node scripts/check-release.mjs`。本文件不取代 CI 的實際結果。
