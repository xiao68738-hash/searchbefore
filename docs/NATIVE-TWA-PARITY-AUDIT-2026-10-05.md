## 本輪原則

- 修正查詢範圍、原登記資訊遺漏優先；不更改任何原始農藥登記、雲端規則、使用者紀錄或 Play 軌道。
- 原生採收期區間顯示回復原文；實際篩選／倒數仍用既有安全核心產出的較長值。
- 特殊用法與型態不符只重新分組；不丟列、不自動推定用途，不提供被禁止的一鍵計算。
- 新增測試必須真正執行後才能標記通過。裝置未接上；後續只使用專屬隔離模擬器，不操作其他專案或私人手機。
- PR148 保持草稿，正式版發布鎖不解除。專用審查帳號仍未備妥，不能虛構帳號或使用私人帳號代替。

## 驗收結果

- 根目錄 47 個 JS 測試檔兩次全數通過（runner 另重跑兩項分類檔，不重複計数）。原登記列維持 17,333、287 作物，資料沒有擴張或改寫。
- 第一個完整原生建置：10分30秒、89 tasks（27執行／62快取）；20 suites／85 JVM tests，0 failures／errors／skipped；Lint `No issues found.`。生成 Manifest 安全基準與合成網站→原生→網站完整備份往返均通過。
- 分類搜尋 JVM 測試逐一比對 185 種查詢 × 289 原防治對象＝53,465 組網站 oracle，包括陰性與別名結果；不是 OCR 或用藥效果準確率。
- 第一個提前建置在補齊報表修改時主动停止，沒有當作通過；完整建置後另作最後字樣與 UI 測試的一致性重建。
- 初次唯讀 API36 模擬器與最後重建同時啟動時，主機可用記憶體降至約 290 MB；已用 `adb -s emulator-5580 emu kill` 關閉本輪模擬器，未關閉其他程式或清除資料。後續須序列執行並以低解析度減少渲染負擔，不把尚未開機當 App 測試結果。
- 本輪已讀電腦操作技能，工具目錄沒有 `node_repl`／`cua_repl`／瀏覽器控制工具，未使用其他管道冒充已登入的 Console 操作。Play／線上 UI 本輪未查證。
