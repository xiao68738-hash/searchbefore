# mrl-data 總索引 ── MRL（農藥殘留容許量）工作地圖

這個資料夾在做一件事：**把 App 端的「中文農藥名 × 作物」比對到衛福部附表一的殘留容許量，判斷某作物噴某藥是否會超標／不得檢出。**

> **安全紅線：** 任何殘留／合法性結論，在經人工確認（狀態＝檢核完成）前，一律不得進 App 或資料管線。名稱查無、分類不明、任一層對照失敗時，只能標「無法確認」，不得推論安全或違規。
>
> **管線只讀 `.json`；所有 `.csv` 為人工檢視用（腳本可重新產生）。**

導覽文件三份，分工如下：
- **本檔（資料夾索引.md）**＝全部檔案的總地圖（先看這份）。
- **README.md**＝管線原理、官方資料來源、六大原則。
- **★先看我-校對說明.md**＝殘留物／作物兩張對照表的「怎麼看、怎麼填」操作指南。

## 資料流總覽（七個階段）

```
[階段0] 官方原始快照
   附表一MRL・許可證・附表五作物分類・免訂清單
        │  fetch-mrl / fetch-reference-data
        ▼
[階段1] 藥名→英文有效成分
   （中文農藥名經許可證轉英文成分；混合劑拆成分）
        │  decompose-mixtures
        ▼
[階段2] 成分→附表一殘留物定義   ← 對照最難的一層
   中文名比對 / 英文名比對 / 免訂比對 / 法規備註規則 / 缺英文名解析 / 藥名同一性
        │  build-residue-master
        ▼  殘留物對照總表.json（成分→殘留物定義）
[階段3] 作物→附表五分類
        │  build-crop-mapping
        ▼  作物分類對照.json
[階段4] 合併判斷「登記但不得檢出」候選
        │  build-nodetect-candidates
        ▼  登記但不得檢出-候選.json（95 筆）
[階段5] 人工複核（安全紅線在這關）
   (A) 殘留物/作物對照名單  ── 任務 #3/#4/#5
   (B) 不得檢出候選逐筆複核 ── 目前核心工作（11–95 已完成）
        │
        ▼
[階段6] 查不到的 → 詢問函問主管機關（食藥署、防檢署均已寄，待回覆）
```

> **同義詞／群組教訓（避免誤刪或漏判）：**
> - 確有同義（同一作物、不同寫法）：薏苡＝薏仁、葉用甘藷＝小葉菜類、甘藍＝十字花科包葉菜類、檬果＝芒果等。
> - **危險的假同義（不可擅自等同，須查證）：** 「胡麻」台灣農藥慣指芝麻(Sesamum indicum)，但中文亦可指亞麻籽(Linum)；附表一同時有「芝麻」「亞麻籽」兩獨立項、容許量不同。作物名在附表一查無時，**先確認登記證的真正作物身分，再決定套哪一列**，不可只憑名稱近似逕自等同（誤等同＝可能誤刪不得檢出警告）。
> - 群組（如茄科果菜類）一律以延伸5.1版逐項展開成員後，再對食藥署附表一/五分類查容許量，**不可只比對群組名稱**。混合劑須「任一成分於該作物缺標準」才成立不得檢出。
