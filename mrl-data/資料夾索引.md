# mrl-data 資料夾索引

殘留容許量(MRL)比對與人工複核的資料與腳本。**安全紅線:任何殘留/合法性結論在經人工確認(狀態=檢核完成)前,不得進 App 或資料管線。**

管線只讀 `.json`;所有 `.csv` 為人工檢視用(腳本可重新產生)。

## 3. 管線腳本(依序)
`fetch-mrl.mjs` / `fetch-reference-data.mjs`(抓資料)→ `build-review-list.mjs`(稽核)→ `decompose-mixtures` / `match-residue-en` / `match-residue-zh` / `match-exempt` / `apply-residue-rules` / `resolve-missing-english` / `verify-name-identity`(各層比對)→ `build-residue-master.mjs`(合併總表)→ `build-crop-mapping.mjs`(作物分類)→ `build-nodetect-candidates.mjs`(產不得檢出候選)→ `build-inquiry-attachment` / `build-inquiry-letters`(詢問函)→ `build-review-workbook` / `build-generic-suggestions`(複核輔助)。共用工具 `lib.mjs`。
